# icd10
Чи бол ахисан түвшний Full-Stack програм хангамжийн архитектор. Надад ICD-10 (Өвчний олон улсын 10 дахь ангилал)-д суурилсан Англи болон Монгол хэлний хайлтын систем (Search Engine / Web App) хэрэгтэй байна.

Эхлээд надад системийн архитектор, дата бүтэц болон зааврыг гаргаж өгөөд, дараа нь кодчиллын хэсэг рүү орно уу.

---

### 1. Миний серверийн орчин (Энэ орчинд тааруулж шийдэл боловсруулна уу):
- Web Server: Apache 2.4.6 (CentOS)
- Language: PHP 8.0.30 (mysqli extension)
- Database: MariaDB 10.6.7 (Charset: utf8mb4 / utf8mb4_unicode_ci)
- Architecture: Single-server environment (Localhost / UNIX socket)

---

### 2. Төслийн функциональ шаардлага:
- Хоёр хэлний хайлтын систем (Англи & Монгол).
- Хайлт хийх боломжууд:
  1. ICD-10 кодоор хайх (жишээ нь: E11, I10, J44 гэх мэт).
  2. Түлхүүр үгээр хайх (Англи болон Монгол үгээр автоматаар MATCH / LIKE хайлт хийх).
- Монгол датаг миний өгөх .txt эсвэл .csv файлаас MariaDB бааз руу импортлох скрипт эсвэл логик хэрэгтэй.
- Англи датаг WHO-ийн ICD-10 2019 (https://icd.who.int/browse10/2019/en) эсвэл бэлэн dataset-ээс бааз руу бэлтгэж оруулах заавар.

---

### 3. Эхний шатанд надад өгөх мэдээлэл (Загвар ба Заавар):
Шууд код бичихгүйгээр дараах зүйлсийг боловсруулж харуулна уу:

1. MariaDB Баазын архитектур:
   - ICD-10 кодыг Англи, Монгол орчуулгатай нь хадгалах хамгийн оновчтой Таблицын бүтэц (DDL SQL script).
   - Монгол кирилл үсгээр хурдан хайхад зориулсан FULLTEXT / Indexing стратеги.

2. Монгол .txt Дата бэлтгэх формат:
   - Би Монгол текстийг ямар бүтцээр (Жишээ нь: `CODE|MN_TITLE|DESCRIPTION`) бэлтгэж өгвөл PHP/MariaDB руу оруулахад хамгийн хялбар вэ? 5 мөр жишээ дата харуулна уу.

3. PHP болон Фронтенд Архитектур:
   - PHP 8.0 + mysqli ашигласан хөнгөн AJAX/Fetch API-тай хайлтын хуудасны ерөнхий бүтэц.

4. Хэрэгжүүлэх дарааллын төлөвлөгөө (Implementation Roadmap).
